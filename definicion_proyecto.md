# Definición del Proyecto: MyAgencia (Nombre Temporal)

## 1. Visión General
Una plataforma web moderna, inmersiva y visualmente impactante para una agencia de viajes premium en Cusco. El objetivo es conectar a los viajeros con experiencias auténticas en el Valle Sagrado, combinando turismo tradicional con experiencias místicas y de aventura.

## 2. Objetivos Principales
1.  **Inspirar**: Usar un diseño visual rico (fotos de alta calidad, videos, animaciones suaves) para transmitir la magia de Cusco.
2.  **Informar**: Proveer detalles claros y atractivos sobre tours y experiencias.
3.  **Vender**: Facilitar la reserva y compra de paquetes personalizados.
4.  **Gestionar**: Proveer al administrador (tú) un registro claro de las ventas para la logística.

## 3. Estructura del Sitio Web

### A. Página de Inicio (Landing Page)
*   **Hero Section**: Video de fondo o carrusel de imágenes impactantes (Machu Picchu, Valle Sagrado, Ceremonias). Título evocador.
*   **Buscador Rápido**: "¿Qué experiencia buscas hoy?" (Aventura, Cultura, Místico).
*   **Destacados**: Carrusel de "Experiencias Imperdibles" (ej. Canotaje, Ayahuasca).
*   **Testimonios/Confianza**: Elementos que den seguridad al viajero.

### B. Catálogo de Experiencias (Tours)
Categorizado para facilitar la búsqueda:
1.  **Valle Sagrado y Arqueología**: Pisac, Ollantaytambo, Moray.
2.  **Aventura y Naturaleza**: Canotaje en el río Urubamba, Cabalgatas, Trekking.
3.  **Misticismo y Bienestar**: Ceremonias de Ayahuasca, Pago a la Tierra, Retiros de conexión natural.
4.  **Paquetes Personalizados**: Opción para "Armar tu viaje".

### C. Página de Detalle de Tour
*   Galería de fotos inmersiva.
*   Itinerario día a día (visual, línea de tiempo).
*   Qué incluye / Qué no incluye.
*   Precio y selector de fechas/personas.
*   Botón de llamada a la acción: "Reservar Ahora".

### D. Sistema de Reservas y Checkout
*   **Carrito de Compras**: Para agregar múltiples experiencias.
*   **Formulario de Datos**: Recopilación de información del pasajero (Pasaporte, dieta, hotel de recojo).
*   **Pasarela de Pago / Contacto**: Integración con pagos (PayPal/Stripe) o botón de WhatsApp/Formulario para cerrar la venta manualmente si se prefiere.
*   **Confirmación**: Envío de correo automático al cliente y al administrador.

### E. Panel de Administración (Logística)
*   Vista de "Nuevas Reservas".
*   Detalle de clientes y fechas.
*   Estado del pago y notas logísticas.

## 4. Stack Tecnológico Propuesto
*   **Frontend**: React + Vite (Velocidad y modernidad).
*   **Estilos**: Tailwind CSS (Diseño responsive y personalizado).
*   **Animaciones**: Framer Motion (Para el efecto "wow").
*   **Base de Datos/Backend**: Firebase (Google) o Supabase.
    *   *Por qué*: Permite autenticación, base de datos en tiempo real (para ver las ventas al instante) y hosting fácil sin configurar servidores complejos.
